# CWシナリオ置き場（ひな形）

CardWirth のシナリオなどを、自分の GitHub で公開するための置き場です。作者様ごとに、このひな形から自分の置き場を作って使います。

**▶ [見本のサイトを見る](https://seihayukimi-oss.github.io/cardwirth-template-dlpage/)**（このひな形で作った見本です。トップページ・作品の紹介ページ・一覧・DLページ・DLキーつきの作品を試せます。ファイルは、中身のない見本です）

## はじめかた（GitHub のアカウントだけで、無料でできます）

1. **自分の置き場を作る**：このページの上の緑の「**Use this template**」→「**Create a new repository**」を押す。名前を決めて（例：`cw-scenario`）、「Public」のまま「Create repository」
2. **公開の設定をする**：できたリポジトリで「**Settings**」→ 左の「**Pages**」を開き、「Build and deployment」の「Source」を「**GitHub Actions**」にする（[自分のリポジトリでは、ここから開けます](../../settings/pages)）
3. **はじめての公開**：「**Actions**」→ 左の「**公開する**」→ 右の「**Run workflow**」→ 緑の「**Run workflow**」を押す（[自分のリポジトリでは、ここから開けます](../../actions/workflows/publish.yml)）
4. 数分で `https://（アカウント名）.github.io/（リポジトリ名）/` に置き場ができます。いちばん下の「**管理ページ**」を開き、「キーの作り方」にそって作者様用のキーを作れば、あとはブラウザだけで作品を置けます

- 「Actions」の結果に「あと1つ、設定が必要です」と出たときは、2 と 3 をやり直してください（結果の画面に、開く場所のリンクも出ます）
- 公開が終わると、「Actions」の結果の画面にサイトと管理ページの住所が出ます

くわしくは [はじめかた](docs/はじめかた.md) をご覧ください。

## できること

- **アップローダー**：置き場の中に、いくつでも作れます。作品ごとに、変わらない DLページの URL（`…/d/1/`）ができます
- **一覧**：タイトル・対応エンジン・ファイル名・コメント・容量・投稿日時・更新日時・DL数（1作品1行。入りきらない分は横にスクロール。検索・並べ替え）
- **管理ページ**（`…/admin/`）：追加・ファイルの差し替え・編集・削除（作者様用のキーを持つ人だけ）
- **公開範囲**：公開／限定公開（URL を知っている人だけ）／非公開。アップローダーごと・作品ごと・ページごとに選べます
- **DLキー**：付けた作品は、ブラウザの中で暗号化してから置きます。キーを知っている人だけが、DLページで元のファイルに戻せます
- **ページ（HP）**：Wiki記法で、トップページ・作品の紹介ページ・メニューを作れます。作品のDLカードや一覧を埋め込んだり、画像を押すとダウンロードできるようにしたりできます
- **デザイン**：ヘッダー・フッター・背景の色や画像、メニューの位置（右・左・上・右上のボタンで開く）を選べます。サイトの枠（テンプレート）と CSS も変えられます
- **CWカタログ**：「CWカタログで共有する」にした作品だけ、CWカタログのデータ形式（format 1）の JSON を公開します（何もしなければ、JSON は出しません）

文書：[はじめかた](docs/はじめかた.md)・[Wiki記法](docs/Wiki記法.md)

## しくみ

| もの | 場所 |
|---|---|
| アップローダー・作品の情報 | `data/items.json`（管理ページが書きます） |
| ページ・メニュー・テンプレート・CSS | `data/pages.json`（管理ページが書きます） |
| ページに入れる画像 | `media/` |
| ファイルの本体 | Releases の「files」（`f作品番号.r版.bin`）。公開のときにサイトへ写します |
| DL数 | Releases の「files」にある、数える用の小さなファイル（`c作品番号.txt`）が取得された回数 |
| 届いたばかりのファイル | `inbox` ブランチ（受け取り箱。公開の作業が Releases へ移して、空にします） |
| 公開 | Actions の「公開する」が、ページをすべて出来上がった HTML にして、GitHub Pages に置きます |
| 見本のサイトのデータ | `sample/`。ひな形のリポジトリ（テンプレートの印つき）で公開するときだけ使います。ひな形から作った自分の置き場では使われません（消してもかまいません） |

DLページは出来上がった HTML なので、スクリプトを動かさない道具（CWカタログの「URLから取得する」など）からも、ファイルへのリンクを読めます。

## 知っておいてほしいこと

- **R18（成人向け）の作品・素材は、この置き場には置けません。** ファイルもページも GitHub の上に置かれるため、GitHub の決まり（[Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies)・[Sexually Obscene Content](https://docs.github.com/en/site-policy/acceptable-use-policies/github-sexually-obscene-content)）に従う必要があります。GitHub は、ポルノにあたるものや、性行為のあからさまな描写を認めていません（写真だけでなく、イラスト・CG・文章も含まれます）。DLキーを付けても、限定公開・非公開にしても、GitHub の上にあることは変わらないので、同じです
  - **R15 の作品・素材は、中身によります。** 性的な表現がひかえめなもの・あからさまな描写のないものは、決まりの上では禁止されていません（GitHub は、芸術・教育などの文脈での表現を認めることがある、としています）。ただし、どこまでがよいかを決めるのは GitHub です。迷うものは置かないのが安全です。理由のない過度な暴力・残酷な描写も、GitHub の決まりで制限されています
  - 決まりに反すると GitHub が判断したときは、置いたものや置き場の住所が使えなくなることがあります。R18 の作品は、成人向けの作品を受け付けている配布サイトに置いて、ページから外のリンクとして案内する形をおすすめします（リンク先の画像や、あからさまな紹介文は、この置き場には載せないでください）
  - このため、管理ページの「対象年齢」で選べるのは「全年齢」と「R15」だけです。タグに「R18」と書いても、R18 の作品は置けません
- 1ファイル95MBまで、置き場ぜんぶで1GBまでが目安です（GitHub Pages の決まり）
- 書いた内容は、だれでも見られる形で GitHub に保存され、変更の履歴も残ります（消したものも、履歴には残ります）
- **限定公開・非公開は、サイトの上での話です**。リポジトリそのものは公開なので、GitHub でリポジトリの中を直接見る人には、タイトルや限定公開の URL が分かります。本当に隠したいファイルには、DLキーを付けてください
- DLキーは保存されません。忘れると、作者様でも元に戻せません（ファイルを選び直して、新しいキーを付けてください）。短いキーは総当たりで当てられやすいので、長めのキーをおすすめします
- DL数は、サイトの「ダウンロード」を押した回数です。CWカタログなどから直接取得した分は数えません
- 試験：`node --test scripts/build.test.mjs`
