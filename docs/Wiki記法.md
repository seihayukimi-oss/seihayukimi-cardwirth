# Wiki記法（ページの書き方）

ページ（HP）とメニューは、次の記法で書きます。管理ページのボタンを押すと、同じものが入ります。
書いた文字はすべて文字として出ます（HTML のタグは効きません）。

## 文字

| 書き方 | 意味 |
|---|---|
| `''文字''` | 太字 |
| `'''文字'''` | 斜体 |
| `%%文字%%` | 取り消し線 |
| `%%%文字%%%` | 下線 |
| `&sup(){文字}` ／ `__文字__` | 上付き ／ 下付き |
| `&size(20){文字}` | 文字の大きさ（6〜72） |
| `&color(red){文字}` ／ `&color(red,#ffe){文字}` | 文字の色 ／ 文字の色と背景の色 |
| `&align(center){文字}` | 寄せる（left・center・right） |
| `文字((説明))` | 注釈（ページの下に出ます） |
| `~~` | その場で改行 |

## 行の頭に書くもの

| 書き方 | 意味 |
|---|---|
| `*見出し` ／ `**見出し` ／ `***見出し` | 見出し（大・中・小） |
| `-文字` ／ `--文字` ／ `---文字` | 箇条書き（`-` の数で段） |
| `+文字` ／ `++文字` ／ `+++文字` | 番号つきリスト |
| `>文字` | 引用 |
| `----` | 水平線 |
| `#contents` | 目次（見出しから自動で作ります） |
| `//文字` | コメント（ページには出ません） |
| `=\|\|` 〜 `\|\|=` | 書いたとおりに出す（`=\|BOX\|` で枠つき、`=\|AA\|` でアスキーアート向け） |
| `[+]見出し` 〜 `[END]` | 折りたたみ（`[-]` なら開いた状態） |
| `=\|CODE\|` 〜 `\|\|=` | コードの枠（書いたとおりに出て、「コピー」のボタンが付きます。書き方を人に見せるときに） |
| `=\|SAMPLE\|` 〜 `\|\|=` | 書き方の見本（書いたコードと、その出来上がりを並べて出します） |

空の行で段落が分かれます。

## リンク・画像

| 書き方 | 意味 |
|---|---|
| `[[ページ名]]` ／ `[[文字>ページ名]]` | 置き場の中のページへのリンク |
| `[[文字>https://…]]` ／ `[[文字>>https://…]]` | 外のサイトへのリンク ／ 別のタブで開く |
| `[[文字>#h-2]]` ／ `&aname(名前)` と `[[文字>#名前]]` | ページの中の場所へのリンク（見出しは上から h-1、h-2…） |
| `https://…` | そのままリンクになります（画像の URL は画像になります） |
| `&ref(画像)` ／ `&ref(画像,幅,高さ)` | 画像。「画像」ボタンで置いた画像はファイル名で、外の画像は URL で書きます |
| `[[画像のURL>リンク先]]` | 画像をリンクにする |

## 画像や文字を押して、ダウンロードできるようにする

| 書き方 | 意味 |
|---|---|
| `&dl(作品番号){&ref(画像)}` | 画像を押すと、その作品をダウンロードします（DL数も数えます） |
| `&dlpage(作品番号){&ref(画像)}` | 画像を押すと、その作品の DLページへ進みます |
| `&dl(作品番号){文字}` ／ `&dlpage(作品番号){文字}` | 文字でも同じように書けます |

- DLキーを付けた作品は、`&dl` でも DLページへ進みます（DLキーを入れてもらうため）
- 管理ページでは、先に `&ref(画像)` を選んでから「作品を埋め込む…」→「押すとDLできる画像・文字」を選ぶと、自動で囲みます
- バナーの画像の上に、版や対象レベルを文字で添える書き方の例：

```
**サンプル店　ver1.00　店シナ／Lv1～3
&dl(1){&ref(banner.png)}
```

## 表

```
|~見出し1|見出し2|
|内容1|内容2|
|left:左寄せ|bgcolor(#ffe):色つき|
|>|右とつなげる|
```

| セルの頭 | 意味 |
|---|---|
| 行の頭に `~` | その行を見出しにする |
| `!` | そのセルだけ見出しにする |
| `left:`・`center:`・`right:` | 寄せる |
| `bgcolor(色):`・`color(色):`・`size(数字):` | 背景の色・文字の色・大きさ |
| `>` だけ ／ `^` だけ | 右のセルとつなげる ／ 上のセルとつなげる |

## 置き場の部品を埋め込む

行にこれだけを書きます。

| 書き方 | 入るもの |
|---|---|
| `#dl(作品番号)` | その作品の DLカード（タイトル・版・容量・DL数・ダウンロードのボタン） |
| `#dllist()` | 公開している全作品の一覧 |
| `#dllist(アップローダーの番号)` | そのアップローダーの作品の一覧 |
| `#uploaders()` | アップローダーの一覧 |
| `#pagelist()` | ページの一覧 |
| `#recent(5)` | 最近の更新（数字は件数） |

番号は、管理ページの「作品を埋め込む…」から選ぶと自動で入ります。非公開の作品は、埋め込んでも出ません。
