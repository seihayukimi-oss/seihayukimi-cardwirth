# はじめかた（作者様へ）

GitHub のアカウントがあれば、無料で始められます。設定は最初の1回だけです。

## 1. 自分の置き場を作る

1. ひな形のリポジトリのページで、上の緑の「**Use this template**」→「**Create a new repository**」を押す
2. 「Repository name」に名前を書く（例：`cw-scenario`）。名前はサイトの住所になります（`https://アカウント名.github.io/名前/`）。使い始めてから変えると、DLページの URL も変わるので、ここで決めてください
3. 「Choose visibility」は「**Public**」のまま（無料で公開するには Public が必要です）。「Include all branches」はオフのまま
4. 「**Create repository**」を押す
5. できたリポジトリの「**Settings**」→ 左の「**Pages**」を開き、「Build and deployment」の「Source」を「**GitHub Actions**」にする
6. 「**Actions**」タブ → 左の「**公開する**」→ 右の「**Run workflow**」→ 緑の「**Run workflow**」を押す（最初の1回だけ）

数分で、`https://（アカウント名）.github.io/（リポジトリ名）/` に置き場ができます。「Actions」の結果の画面に、サイトと管理ページの住所が出ます。

- 作った直後に「公開する」が自動で動いて、「あと1つ、設定が必要です」と出ることがあります。そのときは 5 と 6 をしてください（失敗ではありません）
- 「Actions」タブに「I understand my workflows…」の緑のボタンが出たときは、押してから 6 をしてください

## 2. 作者様用のキーを作る

管理ページを開くためのキーです。人に見せないでください。

1. サイトのいちばん下の「**管理ページ**」を開き、「キーの作り方（はじめての方）」を開く
2. 「**キーを作る画面を開く**」を押す。GitHub の画面が、名前・権限（Contents：Read and write）・期限（1年）が入った状態で開きます
3. 「Repository access」で「**Only select repositories**」を選び、「Select repositories」から**自分の置き場のリポジトリだけ**を選ぶ（ここだけは自分で選ぶ必要があります）
4. いちばん下の緑の「**Generate token**」を押し、出てきたキー（`github_pat_` で始まる文字）をコピーする。キーは二度と表示されないので、控えてください
5. 管理ページに戻り、キーを貼って「開く」

期限が切れたら、同じ手順で作り直します。キーをなくしたときも、作り直せば大丈夫です（前のキーは GitHub の「Settings」→「Developer settings」→「Personal access tokens」で消せます）。

## 3. 作品を置く

1. 置き場の「管理ページ」（`…/admin/`）を開き、キーを入れて「開く」
2. 「アップローダー」の一覧で、置きたいアップローダーの「管理画面」を押す（「＋新規アップローダー」で増やせます）
3. 「＋新しい作品を追加」→ タイトル・ファイル・コメント・タグなどを書いて「保存する」
4. 数分で、一覧と DLページに出ます（「公開の進み具合」で確かめられます）

- **まとめて追加**：「＋まとめて追加」→ ファイルをいくつも選ぶ（ドロップでも）→ タイトル・バージョン・コメントを直して「まとめて登録する」。タイトルとバージョンはファイル名から入ります。タグ・形式・対象年齢・公開範囲などは、全部の作品に共通で1回だけ選びます。DLキーつきの作品は、1作品ずつの追加からお願いします
- **差し替え**：「編集」→ 新しいファイルを選んで保存。DLページの URL は変わりません
- **タイトルなどの変更**：「編集」→ 直して保存（ファイルは選ばなくて大丈夫です）
- **削除**：「削除」→「本当に削除する」
- **DLキー**：ファイルを選ぶときに入れます。付ける・変える・外すときは、ファイルを選び直します
- **対応エンジン**：1.50・Next・Py のそれぞれに、確認済み・動くはず・非対応・未確認を選べます（選ばなければ、形式から自動で決めます）

## 4. 公開範囲を決める

アップローダーごと・作品ごと・ページごとに選べます。

| 公開範囲 | どうなるか |
|---|---|
| 公開 | 一覧に出ます |
| 限定公開 | 一覧には出ません。推測できない URL になり、URL を知っている人だけが見られます（企画のファイル置き場などに） |
| 非公開 | サイトには出ません（管理ページにだけ出ます） |

- アップローダーを限定公開にすると、その URL を知っている人には、中の作品が並んで見えます
- アップローダーと作品の設定が違うときは、きびしいほうになります
- リポジトリそのものは公開なので、GitHub でリポジトリの中を直接見る人には分かります。本当に隠したいファイルには、DLキーを付けてください

## 5. ページ（HP）を作る

管理ページの「ページ（HP）」で、Wiki記法のページを作れます（書き方は [Wiki記法](Wiki記法.md)）。

- **作品の紹介ページ**：ページを作り、作品の「編集」で「紹介ページ」に選ぶと、DLページからリンクされます。ページの中に `#dl(作品番号)` と書くと、DLカード（ダウンロードのボタンつき）が入ります
- **DLを埋め込んだページ**：`#dllist()`（全作品の一覧）や `#dl(作品番号)` を並べると、1ページでそのままダウンロードできるページになります
- **トップページ**：「このページをトップページにする」にチェックを入れます
- **メニュー**：「メニュー（横の欄）を編集」で、全ページの横に出る欄を作れます
- **画像を押してダウンロード**：`&dl(作品番号){&ref(画像)}` と書くと、バナーの画像を押すだけでダウンロードできます（`&dlpage` なら DLページへ進みます）
- **デザイン**：「デザイン」の「かんたん設定」で、ヘッダー・フッター・ページの背景の色や画像、文字やリンクの色、メニューの位置（右・左・上・右上のボタンで開く）と固定を選べます。もっと細かく変えたいときは、サイトの枠（テンプレート）と CSS も書けます
- **管理ページへのリンク**：フッター（いちばん下）に小さく出ます

## 6. CWカタログで共有する（したい作品だけ）

何もしなければ、CWカタログ用の JSON はどこにも出しません。
作品の「編集」で「CWカタログで共有する」にチェックを入れると、その作品だけ、次のものが出ます。

- DLページに「CWカタログで読む」の URL（`…/d/1/cw-catalog.json`。CWカタログの「DL一覧を読み込む」で使えます）
- 置き場のカタログ（`…/index.json`）への登録（「公開」の作品だけ。トップページをページにしていないときは、トップにも URL が出ます）

DLキーを付けた作品は、配布先が「ページを開いて手動でDL」（DLキーが必要です）になります。DLキーそのものは、決して入りません。

共有しなくても、CWカタログの「URLから取得する」に DLページの URL を入れると、DLキーなしの作品はファイルを取得できます。
