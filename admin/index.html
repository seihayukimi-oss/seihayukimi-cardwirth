管理ページサイトを見るキーを忘れさせる

作者様用のキーを入れる

このページは、この置き場の持ち主（作者様）だけが使えます。GitHub で作った「アクセストークン」をキーとして使います。キーは GitHub（api.github.com）にだけ送ります。

キーの作り方（はじめての方）

キーは、この置き場の中身を書き換えるための「合いかぎ」です。GitHub の画面で作ります。

  1. GitHub にログインした状態で、下の「キーを作る画面を開く」を押す（名前・権限・期限が入った状態で開きます）
  2. 「Repository access」で「Only select repositories」を選び、「Select repositories」からこの置き場のリポジトリだけを選ぶ（ここだけは自分で選ぶ必要があります）
  3. 「Permissions」の「Contents」が「Read and write」になっていることを確かめる（ほかは変えない）
  4. いちばん下の緑の「Generate token」を押し、出てきたキー（github_pat_ で始まる文字）をコピーして、上の「キー」の欄に貼る

キーを作る画面を開く（GitHub）

キーは二度と表示されないので、パスワードの管理アプリやメモ帳などに控えてください。人に見せないでください。期限（最初は1年）が切れたら、同じ手順で作り直します。

ここに書いた内容（タイトル・コメント・ページの文など）は、だれでも見られる形で GitHub に保存され、変更の履歴も残ります。「限定公開」「非公開」にしたものも、GitHub のリポジトリを直接見る人には見つけられます（本当に隠したいファイルには、DLキーを付けてください）。DLキーと、DLキーを付けたファイルの中身は保存されません（暗号化したものだけを置きます）。
